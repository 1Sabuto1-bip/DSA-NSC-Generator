# Aventurischer NSC-Namensgenerator

Version 0.2.0 erzeugt Namen für Menschen und weitere aventurische Spezies. Das Projekt ist eine statische Webseite und kann direkt über GitHub Pages sowie als Owlbear-Rodeo-Erweiterung genutzt werden.

## Inhalt

- Menschen aus Andergast und Thorwal
- Achaz
- Au-, Wald-, Firn-, Steppen- und Hochelfen sowie Shakagra
- Stammes- und Stadtgoblins
- Grolme, Oger, Orks und Trolle
- mehrere Zwergenvölker einschließlich Brobim, Roter Zwerge und Tiefzwerge
- dynamische Schriftgröße für lange Namen
- für die Einbettung in Owlbear Rodeo angepasste Darstellung

## Veröffentlichung

Der fertige GitHub-Pages-Stand liegt im Ordner `docs`. Eine genaue Anleitung befindet sich in `GITHUB-UPLOAD-ANLEITUNG.md`.

Nach der Veröffentlichung im Repository `DSA-NSC-Generator`:

- Webseite: `https://1sabuto1-bip.github.io/DSA-NSC-Generator/?v=020`
- Owlbear-Manifest: `https://1sabuto1-bip.github.io/DSA-NSC-Generator/manifest.json?v=020`

## Quelle

Die Namensbildung basiert auf *Aventurische Namen*: Andergast S. 12, Thorwal S. 57–58 und Namen anderer Spezies S. 76–89. Enthalten sind strukturierte Namensbestandteile und kurze eigene Zusammenfassungen, keine längeren Buchtexte.
